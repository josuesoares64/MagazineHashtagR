# MagazineHashtagR

Este repositório faz parte das aulas do **Curso de React da Hashtag Treinamentos**.  
O objetivo é praticar os fundamentos do React, incluindo componentes, props, estados, eventos, organização do projeto e uso de ferramentas modernas de desenvolvimento.

## 🎯 Objetivo do Projeto

Desenvolver uma aplicação React simples para reforçar:
- Estrutura e criação de componentes;
- Passagem de dados entre componentes;
- Manipulação de estado;
- Renderização condicional;
- Estilização básica;
- Organização de pastas;
- Uso do Vite no ambiente de desenvolvimento.

## 🛠️ Tecnologias Utilizadas

- **React.js**
- **JavaScript (ES6+)**
- **Vite**
- **CSS / Tailwind (se aplicado)**
- **Node.js & npm**
